CSS Width and Height

CSS width and height properties help us control the size of HTML elements on a webpage.

1. Width Property

This box has a width of 300px.

2. Height Property

This box has a height of 150px.

3. Width and Height Together

Width: 250px
Height: 120px

4. Max Width

This box can grow up to 400px wide, but it will not exceed that limit.

5. Min Width

This box will not become narrower than 200px.

6. Min Height

This box has a minimum height of 100px.

7. Max Height

This box has a maximum height of 100px. When the content becomes larger than the available space, a scrollbar appears so that users can read the remaining content. CSS helps us control the size of elements and manage extra content inside them.

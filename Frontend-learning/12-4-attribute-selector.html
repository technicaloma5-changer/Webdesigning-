What I Learned

  • [type="text"] selects an exact attribute value.
  • [target="_blank"] matches a specific target value.
  • [class~="highlight"] matches a complete word.
  • [href^="https"] matches values that start with a string.
  • [title*="CSS"] matches values containing a string.

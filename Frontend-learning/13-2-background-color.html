CSS Background Color

The CSS background-color property is used to set the background color of an HTML element.

Example 1: Named Color

This box uses the lightblue color as its background.

Example 3: Hexadecimal Color

The background color of this box is set using the hexadecimal color code #d1fae5.

Remember: The background-color property changes the background color of an element, not its text color.

CSS Padding

Padding is used to create space between the content of an element and its border.

1. Padding on All Sides

This box has 30px padding on all four sides.

2. Individual Padding Properties

Top: 10px
Right: 30px
Bottom: 40px
Left: 50px

3. Two-Value Padding

Padding: 20px 40px;

Top and Bottom: 20px
Left and Right: 40px

4. Three-Value Padding

Padding: 15px 30px 40px;

Top: 15px
Left and Right: 30px
Bottom: 40px

5. Four-Value Padding

Padding: 10px 20px 30px 40px;

Top: 10px
Right: 20px
Bottom: 30px
Left: 40px

6. Padding with Box Sizing

This box has a total declared width of 300px, including its padding and border.

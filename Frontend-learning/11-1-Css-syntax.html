Introduction to CSS Syntax

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML elements and control how a webpage looks.

CSS makes webpages more attractive and easier to read.

Understanding CSS Syntax

A CSS rule contains a selector and a declaration block. Each declaration consists of a property and a value. 

h1 {
    color: blue;
    font-size: 32px;
}

Selector: h1 selects all h1 elements.
Property: color specifies which text color to use.
Value: blue is the color assigned to the property.

CSS Properties and Values

CSS properties control different visual aspects of an element, such as its color, size and spacing.

  • color: Changes text color.
  • font-size: Changes text size.
  • background-color: Sets the background color.
  • text-align: Aligns text horizontally.

Why Are CSS Comments Useful?

Comments help explain what a CSS rule does. They are useful when reviewing code or returning to a project after some time.

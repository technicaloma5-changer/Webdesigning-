CSS Element Selector

An element selector is used to select HTML elements by their tag names and apply CSS styles to them.

What Will You Learn?

With element selectors, we can style multiple elements of the same type without adding a class or ID to each one.

Examples of Element Selectors

  • h1 selector styles all main headings.
  • h2 selector styles all second-level headings.
  • p selector styles all paragraphs.
  • li selector styles all list items.

Why Use Element Selectors?

Element selectors are useful when we want to apply consistent styling to every element of a particular type.

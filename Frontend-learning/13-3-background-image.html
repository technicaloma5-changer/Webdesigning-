Explore the Beauty of Nature

Learn how CSS background images can make a webpage more attractive and visually appealing.

1. Background Image

The background-image property adds an image behind an element's content. 

background-image: url("image.jpg");

2. Background Size

The background-size: cover; property makes the image cover the entire section. Some parts of the image may be cropped.

3. Background Position

The background-position: center; property keeps the main part of the image centered.

4. Background Repeat

The background-repeat: no-repeat; property prevents the image from repeating across the section.
